মশিউর এন্টারপ্রাইজ LPG — প্রাথমিক মোবাইল অ্যাপ

এই ZIP-এ একটি সাধারণ PWA/ওয়েব অ্যাপের সোর্স ফাইল আছে। এটি এখনই APK নয় এবং Firebase/অনলাইন সিঙ্ক সংযুক্ত নয়।

চালানোর সহজ উপায়:
১) ZIP ফাইল Extract করুন।
২) index.html একটি আধুনিক ব্রাউজারে খুলে পরীক্ষা করুন।
৩) হিসাব এই ডিভাইসের ব্রাউজারের Local Storage-এ থাকবে। ব্রাউজারের ডেটা মুছলে হিসাব হারাতে পারে—নিয়মিত 'ব্যাকআপ ডাউনলোড' ব্যবহার করুন।

গুরুত্বপূর্ণ:
- এই প্রোটোটাইপে বিক্রয়, ক্রয়, বাকি আদায়, খরচ ও JSON ব্যাকআপের প্রাথমিক ফর্ম আছে।
- স্টক গণনা, গ্রাহক বাকি খাতা, লাভ-লোকসান, লগইন/মালিক-কর্মচারী অনুমতি, Firebase cloud sync এবং APK build এখনো সম্পূর্ণ করা হয়নি।
- বহু মোবাইলে একই হিসাব দেখতে Firebase Authentication ও Firestore-এর নিরাপদ shared-user rules যোগ করতে হবে।
- কোনো Firebase password বা service-account private key কাউকে পাঠাবেন না।
